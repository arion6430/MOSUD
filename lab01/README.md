# lab01. Развёртывание PostgreSQL и загрузка Olist

**Версия PostgreSQL:** 17.11 (Debian), образ `postgres:17`, поднят через
`docker-compose.yml`.

**Способ импорта:** CSV скопированы в каталог `/data/olist` внутри
контейнера, загрузка выполнена через `psql \copy` (см. пример в задании)
для каждой из 9 таблиц; после загрузки добавлены первичные и внешние
ключи (`schema.sql`).

**Фактическое число строк:**

| Таблица | Строк |
|---|---|
| customers | 99 441 |
| orders | 99 441 |
| order_items | 112 650 |
| order_payments | 103 886 |
| order_reviews | 99 224 |
| products | 32 951 |
| sellers | 3 095 |
| geolocation | 1 000 163 |
| product_category_name_translation | 71 |

Все значения совпадают с ориентирами из задания. Проверки `check.sql`
(NULL в ключевых полях, «осиротевшие» ссылки) отклонений не выявили.
Выполнена `ANALYZE` по всем таблицам схемы `olist`.
