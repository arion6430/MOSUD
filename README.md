# mosud-course

Репозиторий практических работ по курсу МОСУД (модели и оптимизация
систем управления данными). Данные каждой работы находятся в каталоге
labNN.

Общий набор данных курса — Brazilian E-Commerce Public Dataset by Olist
(https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce),
лицензия CC BY-NC-SA 4.0. CSV-файлы не хранятся в репозитории
(см. `.gitignore`) и загружаются локально в `data/olist` согласно
инструкциям каждой работы.

- [lab01](lab01/) — развёртывание PostgreSQL и загрузка Olist
